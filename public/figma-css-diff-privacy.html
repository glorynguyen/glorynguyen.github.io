Privacy Policy

Figma CSS Diff

Last updated: March 29, 2026

Figma CSS Diff does not collect, store, or transmit any personal user data to any external server. All processing happens entirely within your browser.

1. Overview

Figma CSS Diff is a Chrome DevTools extension that compares rendered browser CSS styles against Figma Dev Mode specifications to help developers detect spacing, typography, and color discrepancies. This privacy policy explains how the extension handles your data.

2. Data We Do NOT Collect

We do not collect or transmit any of the following:

  • Personally identifiable information (name, email, etc.)
  • Browsing history or visited URLs
  • Page content or website data beyond what is needed for local CSS inspection
  • Authentication credentials or API tokens
  • Analytics or usage statistics

3. Local Storage

The extension uses Chrome's built-in storage API exclusively to save your preferences locally on your device (such as last-used settings). This data:

  • Never leaves your device
  • Is never shared with any third party
  • Can be cleared at any time by removing the extension

4. Permissions Explained

Permission Why it's needed
activeTab To inspect the computed CSS styles of the page you are currently viewing and testing.
tabs To detect when the active tab changes so the DevTools panel can refresh its inspection context.
storage To save your preferences locally on your device. No data is sent externally.
Host permissions (<all_urls>) Developers build on various local and production URLs. This permission allows the extension to inspect styles on any page the developer chooses to test.

5. Third-Party Services

Figma CSS Diff does not integrate with, send data to, or rely on any third-party analytics, advertising, or tracking services.

If you choose to paste Figma Dev Mode CSS snippets into the extension panel, that content is processed locally in memory and is never transmitted.

6. Children's Privacy

This extension is intended for software developers and does not target or knowingly collect information from children under the age of 13.

7. Changes to This Policy

If this privacy policy is updated, the "Last updated" date at the top of this page will be revised. Continued use of the extension after changes constitutes acceptance of the updated policy.

8. Contact

If you have any questions about this privacy policy, please open an issue on the project's GitHub repository or contact the developer directly.
