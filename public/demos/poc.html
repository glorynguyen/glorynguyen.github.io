Authoring Evolution: In the Old Approach, content was disconnected from its URL. Authors had to manage a separate "Route" entry just to map a URL to an Article.

Technical Evolution: This created an N+1 problem where the frontend had to query the Route first, wait, and then query the Article. The New Approach flattens this entirely: the Article is the page. We use parallel discovery to find which content type matches the URL, resulting in a cleaner CMS experience and a faster site.
