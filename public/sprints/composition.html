FullTile System

A composable layout pattern for high-impact grid items.

1. Component Anatomy

Slot: topLeft
Slot: topRight
Main Content {children}
Variant Specific UI

The TileWrapper acts as a layout stage. It handles:

  • The Shell: Overflow hidden, Border Radius, Aspect Ratio.
  • The UI Layer: Absolute positioning for metadata (Top Left/Right).
  • Z-Index Management: Ensuring background media stays behind text.

2. Usage Rules

✅ DO:

  • Use the isFocused prop to trigger the high-contrast state.
  • Keep metadata (Top Left) limited to short strings (e.g., "Work — Category").
  • Ensure all background images have an object-cover class.

❌ DON'T:

  • Don't put interactive buttons in the topLeft slot.
  • Don't override the padding in variants; keep the p-4 or p-8 consistent across the system.
