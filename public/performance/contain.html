CSS Performance

The contain Property

Isolate DOM subtrees so the browser skips unnecessary layout, paint, and style recalculations — improving rendering performance in complex UIs.

01   Paint Containment

Without repaints spill 
.card {
  /* no containment */
  width: 80px;
  height: 80px;
}
→ overflowing content leaks →

The browser must check the entire page for repaint regions. Animating children can trigger costly full-page compositing.

With paint isolated 
.card {
  contain: paint;
  width: 80px;
  height: 80px;
}
→ overflowing content leaks →

Content is clipped to the element. The browser skips painting descendants when the box is offscreen, and limits repaint to this subtree.

02   Layout Containment

Without layout leaks 
.card {
  /* floats & fixed escape */
}
Card A
flt
Sibling shifted by float ↑

A float or absolutely-positioned child can affect siblings and ancestors, forcing the browser to recalculate layout across the whole page.

With layout isolated 
.card {
  contain: layout;
  /* floats & fixed stay inside */
}
Card A
flt
Sibling is unaffected ✓

Layout changes stay within the container. Floats, absolute, and fixed children use the card as their containing block — siblings are not impacted.
